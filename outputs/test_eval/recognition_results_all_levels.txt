RECOGNITION RESULTS - Rank-1 accuracy (%) at occlusion levels 10% to 90%

Baseline                        = standard GaitBase
Detector-guided model selection = an occlusion detector checks each test sequence.
                                  If it finds occlusion, the sequence is matched
                                  with a GaitBase trained on occluded data.
                                  Otherwise it uses the standard GaitBase.
(+x.xx)                         = gain (Rank-1 points) over the Baseline
Avg gain                        = mean gain over the probe types in that row
Occlusion                       = fraction of the silhouette removed (0.5 = half).
                                  80% of the frames of each test sequence are
                                  occluded. Single run per number.
